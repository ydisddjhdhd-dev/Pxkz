شعار حقوق الطبع والنشر: وفقًا للمادة 107 من قانون حقوق الطبع والنشر لعام 1976، يتم استخدام هذه المادة بموجب بند "الاستخدام العادل" لأنشطة مثل النقد والتعليق والتقارير الإخبارية والتدريس والمنح الدراسية والبحث. الاستخدام العادل هو ممارسة محظورة قانونًا ويمكن اعتبارها انتهاكًا لحقوق الطبع والنشر. الاستخدام غير التجاري أو التعليمي أو الشخصي يميل لصالح الاستخدام
